# Skill Nexis – Python Programming Internship | Week 1

This repository contains my practical work completed during **Week 1 of the Skill Nexis Python Programming Internship**.

## Week 1 Overview

Week 1 focuses on Python fundamentals and control structures, including:

- Python Basics
- Variables and Data Types
- Input and Output
- Operators
- Conditional Statements
- Loops
- Functions
- Modules
- String Manipulation
- List Manipulation
- Object-Oriented Programming basics

## Practical Work

### Practice Set

The Week 1 practice set includes:

1. Area of a Circle
2. Even or Odd Number
3. Factorial Using Recursion
4. Count Vowels and Consonants
5. Fibonacci Sequence

### Assignments

#### 1. Temperature Converter
A Python program to convert temperatures between Celsius and Fahrenheit using functions.

#### 2. Student Grade Calculator
A program that accepts student marks, calculates the average, and assigns a grade.

#### 3. Even, Odd & Prime Number Checker
A program that checks whether a number is even or odd and determines whether it is prime.

### Mini Project – Simple ATM Simulator

A console-based ATM simulator implemented using Python.

Features:

- PIN-based login
- Check balance
- Deposit money
- Withdraw money
- Exit option
- Functions for ATM operations
- Input validation

### Project 1 – Snake, Water, Gun Game

A Python-based game implementing the Snake, Water, Gun game using conditional statements and user input.

### Project 2 – The Perfect Guess

A number guessing game where the user attempts to guess a randomly selected number.

### Project 3 – Student Library using OOP

A Python-based student library management program demonstrating Object-Oriented Programming concepts.

The project uses classes such as:

- `Library`
- `Student`
